# 组织工具桥和业务系统连接

## 背景

大陆 IM 接入层的价值不只是收发消息，还要让 Agent 能安全访问组织知识、客户数据、运营资料和业务系统。

## 目标

把飞书文档、多维表格、知识库、CRM、客户服务、销售跟进和定制服务封装为稳定工具桥，供不同 Agent 按权限调用。

## 范围

- 梳理现有飞书工具的能力和权限边界。
- 定义 CRM、客户状态、销售跟进、服务记录等工具接口。
- 设计工具调用审计和错误提示。
- 明确每条产品线默认可用的工具集合。

## 非目标

- 不在第一阶段接入所有业务系统。
- 不让 Agent 绕过权限直接访问底层数据。

## 验收标准

- 有工具桥接口清单。
- 每个工具有输入、输出、权限和错误处理说明。
- 飞书内部运营线至少有一个完整工具闭环。
- 企业微信和微信线有可扩展的业务工具设计。
