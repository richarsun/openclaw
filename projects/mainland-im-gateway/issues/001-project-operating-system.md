# 建立大陆 IM 接入层项目操作系统

## 背景

龙虾需要从“主力开发客户端”调整为“大陆 IM 接入层、企业消息路由层、组织工具桥”。后续需求入口统一使用 GitHub issue，执行状态统一进入 GitHub Project。

## 目标

- 建立账号级 GitHub Project。
- 明确 issue 模板、状态字段、优先级字段和产品线字段。
- 建立从需求、设计、开发、验证到上线的闭环。

## 范围

- Project 初始化。
- 大 issue 拆分。
- README 和项目说明。
- 后续开发流程约定。

## 验收标准

- Project 已创建。
- 初始大 issue 已创建并加入 Project。
- README 能说明项目定位、架构关系和三条产品线。
- 新需求可以直接以 issue 进入项目。
