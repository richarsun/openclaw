# 飞书内部运营入口

## 背景

飞书是内部生产力工具，适合作为运营、文档、知识库、多维表格和内部协作入口。现有 `extensions/feishu/` 已具备通道和部分飞书工具基础。

## 目标

把飞书打造成内部运营和协作的主入口，让团队可以在飞书中调度 Agent、读写运营资料、生成复盘和沉淀过程数据。

## 范围

- 稳定飞书消息收发和群聊路由。
- 梳理飞书文档、知识库、云空间、多维表格、权限工具的可用边界。
- 定义内部运营场景的默认 Agent、权限和工具集。
- 建立错误提示、账号权限诊断和降级策略。

## 非目标

- 不把飞书做成所有外部客户的统一入口。
- 不在第一阶段重写飞书插件架构。

## 验收标准

- 内部用户可以从飞书稳定触发 Agent。
- Agent 可以按权限调用飞书文档、知识库和多维表格能力。
- 关键错误能返回可行动的中文提示。
- 有一套内部运营场景的端到端演示流程。
