# 企业微信 C 端销售跟进入口

## 背景

企业微信适合承载大规模 C 端客户触达和持续跟进。它天然贴近销售、客户标签、客户群、员工协作和客户生命周期管理。

## 目标

建立企业微信通道能力，让销售团队可以通过企业微信进行客户跟进，同时让 Agent 协助话术生成、客户分层、跟进提醒和状态流转。

## 范围

- 核验企业微信开放接口、消息回调、客户联系、客户群、标签和素材能力。
- 设计企业微信通道适配器边界。
- 设计客户身份、销售归属、会话绑定和人工接管策略。
- 设计销售跟进工具桥，例如客户状态、跟进记录、提醒和话术。

## 非目标

- 不在第一阶段做完整 CRM。
- 不自动替代销售与客户的关键沟通决策。

## 验收标准

- 完成企业微信 API 可行性调研和接口边界说明。
- 形成企业微信通道的最小可用技术方案。
- 定义 C 端销售跟进的核心数据对象和路由规则。
- 有可执行的第一阶段落地任务清单。
