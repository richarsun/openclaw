# 统一路由、权限和审计层

## 背景

飞书、企业微信、微信服务不同人群，但都需要共用身份识别、会话绑定、权限控制、工具授权、人工接管和审计机制。

## 目标

建立跨通道统一的企业消息路由层，让不同 IM 入口可以安全地调用不同 Agent 和组织工具。

## 范围

- 统一用户身份、客户身份、组织身份和通道身份映射。
- 统一会话路由、Agent 绑定、工具 allowlist 和权限策略。
- 统一人工接管、敏感操作确认和审计日志。
- 统一错误提示、降级和模型兜底策略。

## 非目标

- 不要求一次性替换现有所有通道实现。
- 不做和业务无关的权限平台大重构。

## 验收标准

- 有统一路由和权限模型文档。
- 飞书场景能复用该模型。
- 企业微信和微信方案能按同一模型扩展。
- 高风险工具调用有明确审批和审计链路。
